# Lokal rejsetilstand og statisk frontend

RejseFlex hostes som en statisk PWA på GitHub Pages, mens personlige rejser, adresser, indstillinger og senere dokumenter bliver på brugerens enhed. Offentlige app-assets og bevidst publicerede regeldata kan indgå i GitHub-buildet; brugerdata må ikke have en kodevej til repositoryet eller Pages. Dette valg gør løbende publicering enkel uden at gøre GitHub til lager for følsomme rejseoplysninger. En eventuel backend til livefunktioner bliver et særskilt system med en særskilt privatlivsmodel.
